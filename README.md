# S.V.M. Public School, Kharak Jatan (Rohtak)

Official website for **Saraswati Vidya Mandir Public School**, Vill. Kharak Jatan, Dist. Rohtak, Haryana, India.

> *"Quality, a promise, a tradition."*

## Features
- **Interactive 3D Campus Walkthrough** (powered by Three.js & Catmull-Rom splines)
- **Kage ThreeUI Design System** inspired typography (`Instrument Serif` + `Onest`)
- **Real Campus Photography** extracted from campus footage
- **Dynamic Scroll Background Transitions**
- **Online Admission Registration (2026–27)** with 1-click WhatsApp inquiry to `+91 98123 66602`
- **Academic Wings**: Pre-Primary (Nursery) to Senior Secondary (Class XII - Science, Commerce, Arts)
- **Hall of Fame**: 100% Board passing results, 3 Scooty honors, and bicycle awards for 90%+ scorers

## Local Development
```bash
# Start local server
npm start
# Server runs at http://localhost:3000
```
